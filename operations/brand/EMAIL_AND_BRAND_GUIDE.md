**Important limitation:** An HTML email cannot reliably render an SVG, WebP or data-URI image in every email client. To fulfill the logo-in-email requirement, attach/include the **original approved PNG** as an inline MIME image when supported, or use its future HTTPS-hosted PNG URL in a branded HTML email. Gmail default signature cannot be set using the currently available connector actions, so this template does not automatically change the Gmail account signature. Never invent a hosted URL or claim the image appeared unless the resulting sent email is checked.
