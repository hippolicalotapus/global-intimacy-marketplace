# Storefront QA — October 30, 2026

The live Netlify store was inspected in a browser. It still serves the older
87-item research catalogue, and searching `one heart` returns zero matches.
The ONE HEART catalogue and photos exist in GitHub but have not been deployed.

## Corrections prepared

- Search accepts `one heart`, `oneheart`, `one-heart`, reordered words, and
  collection phrases; collection groups and colourways are searchable too.
- Wishlist product search uses the same keyword handling as the catalogue.
- Selecting a collection clears incompatible category, brand and search filters.
- Explore all products returns the entire 103-entry catalogue.
- ONE HEART links use `#one-heart`, including direct entry and refresh.
- The phone navigation puts all five destinations on one row; the header stays
  compact at intermediate screen widths.

## Verified

- All 25 Node smoke, behaviour and supplier-import tests pass.
- Browser searches return 16 ONE HEART designs, five mountain hoodies and one
  Rocky Mountains design as appropriate. All 16 design images decode and load.
- Browser checks cover collection/category switching, brand filtering,
  alphabetical sorting, product details, favourites surviving reload, wishlist
  selection, wishlist search, and opening the generated guest wishlist link.
- Responsive browser checks use 393px phone and 884px unfolded-screen iframes,
  plus the 1363px desktop browser viewport. These are layout checks, not tests
  on a physical Android phone.

## Release state

Publication is paused at the owner's request while these fixes are reviewed.
Netlify sign-in is still required for deployment. The public store is unchanged.
This remains a browser-only preview: enquiry links open an email app; there is no
paid checkout, binding preorder, live inventory or order fulfilment to test.
